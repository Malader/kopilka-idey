# Копилка идей: форма сбора идей

Публичная страница с формой. Заявки падают строками в Google Таблицу, ответственным уходит письмо и сообщение в телеграм, автору идеи приходит автоответ с номером заявки. Хостинг бесплатный, платный будет только домен.

**Всё настроено, проверено и работает.**

## Что внутри репозитория

```
kopilka-idey/
├── index.html          вся страница одним файлом (вёрстка, стили, логика)
├── .nojekyll           отключает лишнюю обработку на стороне GitHub Pages
├── README.md           этот файл
└── apps-script/
    └── Code.gs         приёмник заявок, копия того, что стоит в таблице
```

Отдельного сервера и базы нет: страница статическая, роль бэкенда выполняет скрипт внутри Google Таблицы.

## Как это работает

1. Сотрудник заполняет форму на GitHub Pages.
2. Браузер отправляет данные на веб-приложение Apps Script (адрес прописан в `index.html`, переменная `SCRIPT_URL`).
3. Скрипт дописывает строку на лист «Заявки», отправляет письмо ответственным, рассылает сообщение всем подписчикам телеграм-бота и отвечает автору письмом с номером заявки. Любое из уведомлений может отвалиться, заявка от этого не потеряется: она уже в таблице.
4. Если основной путь отправки не проходит (блокировки, обрыв связи), срабатывает запасной. Чтобы заявка при этом не записалась дважды, клиент шлёт одноразовый номер отправки `submissionId`, а скрипт отбрасывает повтор.

## Телеграм-бот

Бот поднят и подписка работает. Ссылка для сотрудников: <https://t.me/greenway_idea_bank_bot>

Каждый, кто откроет ссылку и нажмёт **Запустить**, попадает в рассылку и начинает получать новые идеи личным сообщением.

| Команда | Что делает |
| --- | --- |
| `/start` | подписаться на новые идеи |
| `/stop` | отписаться, письма при этом не трогаются |
| `/last` | последние 5 заявок: номер, название, дата, автор, тема |
| `/help` | список команд, статус подписки и число подписчиков |

Новая заявка приходит каждому активному подписчику отдельным сообщением: номер, название, автор, почта, тема, срок, готовность участвовать, возможный руководитель, суть, проблема, польза, эффект в цифрах, ресурсы, ссылка на материалы и кнопка на таблицу. Длинные поля обрезаются, чтобы сообщение влезло в лимит телеграма.

Подписчики видны на листе **«Подписчики»**: chat id, имя, ник, дата подписки и статус. Чтобы отключить человека вручную, поменяйте его статус на любой другой, кроме `активен`. Если человек заблокировал бота, скрипт сам поставит ему статус `недоступен` и перестанет ему писать.

Команды бот разбирает по расписанию раз в минуту, то есть ответ на `/start` приходит в течение минуты.

**Закрыть подписку кодовым словом.** По умолчанию подписаться может любой, кто знает ссылку на бота, а в заявках есть ФИО и почта сотрудников. Если бот уйдёт за пределы команды, добавьте в свойства скрипта `TELEGRAM_PAROL` со словом: тогда подписка будет работать только командой `/start слово`. Уже подписанных это не затронет.

Выключить телеграм целиком: функция `otklyuchitTelegram`, она снимает расписание. Письма продолжают приходить, список подписчиков остаётся.

Токен бота лежит в свойствах скрипта (**Настройки проекта → Свойства скрипта**, ключ `TELEGRAM_TOKEN`), а не в коде, потому что репозиторий публичный. Если токен утечёт, его меняют в @BotFather командой `/revoke` и вписывают новый в то же свойство, код трогать не надо.

## Что делать дальше

### Подключить домен (когда заказчик его выберет)

1. Купить домен (`.ru` стоит примерно 200-900 ₽ в год у любого регистратора).
2. В DNS домена добавить записи:
   - для домена вида `ideas.company.ru`: одна запись **CNAME** со значением `malader.github.io`;
   - для домена без поддомена вида `company.ru`: четыре записи **A** на адреса `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`.
3. В репозитории: **Settings → Pages → Custom domain**, вписать домен и сохранить. GitHub сам создаст файл `CNAME`, сертификат HTTPS выпустится автоматически за 10-60 минут.
4. Поставить галочку **Enforce HTTPS**.

Хостинг при этом остаётся бесплатным.

### Добавить или убрать адрес в рассылке писем

В таблице: **Расширения → Apps Script**, в блоке `CONFIG` строка `NOTIFY_EMAILS`, адреса через запятую. Затем обязательно **Начать развертывание → Управление развертываниями → карандаш → Версия: Новая версия → Развернуть**. Без этого правка не применится. Адрес веб-приложения при таком обновлении не меняется, `index.html` трогать не надо.

### Поменять вёрстку формы

Правим `index.html`, коммитим, пушим в `main`. GitHub Pages пересобирает страницу за 1-3 минуты.

## Что стоит знать

**Первое письмо может попасть в спам.** Письма шлются от аккаунта g.nsu.ru, для чужого домена это новый отправитель. Стоит один раз найти письмо в папке «Спам», нажать «Не спам» и добавить адрес в контакты, дальше всё будет приходить во «Входящие».

**Лимиты Google.** Аккаунт Workspace (g.nsu.ru): до 1500 писем в сутки со скрипта. Для формы идей этого с большим запасом хватает. Строк в таблице можно до 10 миллионов ячеек, то есть десятки тысяч заявок.

**Админка.** Отдельной админки нет и пока не нужна: сама таблица её заменяет. Есть колонки «Статус» и «Комментарий» для ручной разметки, фильтры и поиск встроенные, выгрузка в Excel в два клика (**Файл → Скачать → Microsoft Excel**).

**Файлы.** Загрузка файлов на статическом хостинге невозможна, поэтому поле 13 просит ссылку на файл в облаке. Настоящие вложения появятся, когда будет полноценный бэкенд.

**Спам в форме.** Стоит скрытое поле-ловушка и проверка на слишком быстрое заполнение. Для публичной формы обычно достаточно. Если начнёт лететь мусор, следующий шаг, капча (Yandex SmartCaptcha, бесплатна).

**Персональные данные.** Форма собирает ФИО и почту, то есть персональные данные, и хранит их на серверах Google за пределами РФ. Формально по 152-ФЗ база с ПД россиян должна находиться в России. Для внутреннего пилота на это обычно закрывают глаза, но заказчика лучше предупредить письменно. Если требование жёсткое, схема та же по сути, но данные складываются в Яндекс или на российский хостинг, а вёрстку переделывать не придётся. В форме уже есть галочка согласия на обработку ПД, при необходимости к ней прикручивается ссылка на политику.

**Аккаунт скрипта.** Скрипт запускается от имени v.malyshev@g.nsu.ru и имеет права на таблицы этого аккаунта и на отправку писем от его имени. Отозвать можно в настройках аккаунта Google, раздел «Сторонние приложения с доступом к аккаунту».

**Переход на свой бэкенд.** Меняется только адрес в `SCRIPT_URL`. Страница, вёрстка и набор полей остаются прежними.
