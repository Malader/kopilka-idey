# Копилка идей: форма сбора идей

Публичная страница с формой. Заявки падают строками в Google Таблицу, плюс письмо ответственным и автоответ автору идеи. Хостинг бесплатный (GitHub Pages), домен подключается позже одной настройкой.

## Что внутри

```
kopilka-idey/
├── index.html          вся страница одним файлом (вёрстка, стили, логика)
├── .nojekyll           отключает лишнюю обработку на стороне GitHub Pages
├── README.md           этот файл
└── apps-script/
    └── Code.gs         приёмник заявок, ставится в Google Таблицу
```

Отдельного сервера и базы нет: страница статическая, роль бэкенда выполняет скрипт внутри Google Таблицы. Платить нужно только за домен.

---

## Шаг 1. Приёмник заявок (15 минут, делается один раз)

1. Создайте Google Таблицу: <https://sheets.new>. Назовите её, например, «Копилка идей, заявки».
2. В таблице: **Расширения → Apps Script**.
3. Удалите всё, что в открывшемся файле `Code.gs`, и вставьте содержимое `apps-script/Code.gs` из этого репозитория.
4. В блоке `CONFIG` сверху поправьте:
   - `NOTIFY_EMAILS`: на какие адреса приходят письма о новых заявках (несколько через запятую);
   - `SEND_CONFIRMATION`: слать ли автору идеи письмо «заявка принята» (`true` или `false`);
   - `PROJECT_NAME`: как подписывать письма.
5. Сохраните (значок дискеты или Ctrl+S).
6. Проверьте, что всё работает: в списке функций сверху выберите `testSubmit` и нажмите **Выполнить**. Google попросит разрешения, нажмите **Разрешить доступ**, выберите свой аккаунт, затем **Дополнительные настройки → Перейти к проекту (небезопасно)** и **Разрешить**. Это нормальный экран для своих скриптов.
   После этого в таблице появится лист «Заявки» с тестовой строкой, а на почту придёт письмо. Тестовую строку потом удалите.
7. **Развернуть → Новое развертывание**. Шестерёнка рядом с «Выберите тип» → **Веб-приложение**. Далее:
   - «Запуск от имени»: **Я** (ваш аккаунт);
   - «У кого есть доступ»: **Все** (это обязательно, иначе форма не сможет отправлять данные);
   - **Развернуть**.
8. Скопируйте выданный **URL веб-приложения**. Он выглядит так:
   `https://script.google.com/macros/s/AKfycb.../exec`

> Если позже правите `Code.gs`, не забудьте **Развернуть → Управление развертываниями → карандаш → Версия: новая → Развернуть**. Без этого правки не применятся, а URL останется прежним.

## Шаг 2. Связать форму с приёмником

Откройте `index.html`, найдите вверху блока `<script>` строку:

```js
var SCRIPT_URL = '';
```

и вставьте URL из шага 1:

```js
var SCRIPT_URL = 'https://script.google.com/macros/s/AKfycb.../exec';
```

Пока строка пустая, форма работает в режиме превью: проверяет заполнение, показывает экран «спасибо», но никуда ничего не отправляет. Удобно показывать заказчику до того, как всё настроено.

## Шаг 3. Выложить на GitHub Pages

```bash
cd kopilka-idey
git init
git add .
git commit -m "Копилка идей: форма сбора идей"
git branch -M main
git remote add origin https://github.com/ВАШ_АККАУНТ/kopilka-idey.git
git push -u origin main
```

Репозиторий должен быть **публичным** (на бесплатном тарифе GitHub Pages работает только с публичными). Дальше в репозитории: **Settings → Pages → Source: Deploy from a branch → Branch: `main`, папка `/ (root)` → Save**.

Через 1–3 минуты страница будет по адресу:

```
https://ВАШ_АККАУНТ.github.io/kopilka-idey/
```

## Шаг 4. Подключить домен (когда заказчик его выберет)

1. Купить домен (`.ru` стоит примерно 200–900 ₽ в год у любого регистратора).
2. В DNS домена добавить записи:
   - для домена вида `ideas.company.ru`: одна запись **CNAME** со значением `ВАШ_АККАУНТ.github.io`;
   - для домена без поддомена вида `company.ru`: четыре записи **A** на адреса `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`.
3. В репозитории: **Settings → Pages → Custom domain**, вписать домен и сохранить. GitHub сам создаст файл `CNAME`, сертификат HTTPS выпустится автоматически за 10–60 минут.
4. Поставить галочку **Enforce HTTPS**.

Хостинг при этом остаётся бесплатным, платный только домен.

## Проверка перед сдачей

- [ ] Отправить тестовую заявку с телефона и с компьютера.
- [ ] Строка появилась в таблице, номер заявки увеличивается.
- [ ] Письмо пришло ответственным, кнопка «Открыть таблицу заявок» ведёт куда надо.
- [ ] Автору пришёл автоответ (проверьте и папку «Спам»).
- [ ] Попробовать отправить пустую форму: должны подсветиться красным незаполненные поля.
- [ ] Ввести почту без собачки: должна ругнуться.
- [ ] Не поставить галочку согласия: отправка не проходит.

## Что стоит знать

**Лимиты Google.** Бесплатный аккаунт Gmail: до 100 писем в сутки со скрипта (для аккаунтов Google Workspace это 1500). Для формы идей этого с большим запасом хватает. Строк в таблице можно до 10 миллионов ячеек, то есть десятки тысяч заявок.

**Админка.** Отдельной админки нет и пока не нужна: сама таблица её заменяет. Есть колонки «Статус» и «Комментарий» для ручной разметки, фильтры и поиск встроенные, выгрузка в Excel через **Файл → Скачать → Microsoft Excel (.xlsx)**. Доступ выдаётся кнопкой «Поделиться» по адресам сотрудников.

**Файлы.** Загрузка файлов на статическом хостинге невозможна, поэтому поле 13 просит ссылку на файл в облаке. Настоящие вложения появятся, когда будет полноценный бэкенд.

**Спам.** Стоит скрытое поле-ловушка и проверка на слишком быстрое заполнение. Для публичной формы обычно достаточно. Если начнёт лететь мусор, следующий шаг, капча (Yandex SmartCaptcha, бесплатна).

**Персональные данные.** Форма собирает ФИО и почту, то есть персональные данные, и хранит их на серверах Google за пределами РФ. Формально по 152-ФЗ база с ПД россиян должна находиться в России. Для внутреннего пилота на это обычно закрывают глаза, но заказчика лучше предупредить письменно. Если требование жёсткое, вариант тот же по сути, но данные складываются в Яндекс или на российский хостинг. В форму уже добавлена галочка согласия на обработку ПД, при необходимости к ней прикручивается ссылка на политику обработки ПД.

**Возврат к загрузке файлов и полноценной админке.** Страница и разметка не меняются, меняется только то, куда уходит `SCRIPT_URL`. То есть переход со связки «GitHub Pages + Таблица» на свой бэкенд не потребует переделывать вёрстку.
